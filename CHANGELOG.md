# Changelog

## 1.0.0

- First release: the port runs the board — the 68000 and Z80 programs translated to C++ by cps2recomp,
  on the toolkit's own machine (no emulator).
- The launcher (ROM set chosen and checked by CRC-32, controls, Play), the in-game menu (save states,
  Insert coin, Player 2 joins, Reset, Quit), stop/step/slow, run-ahead and the Display options.
- Ready-made builds for Windows x64, Linux x86_64 and the Steam Deck (AppImage).
- No game-specific features yet; see [ROADMAP.md](ROADMAP.md).
